# input/

Your shared personal input, used by every part of the workspace.

- `profile.md`: who you are, what you're looking for, and your working rules for Claude. Claude reads
  it at the start of every session. Created during first-time setup from `example/profile.md`.
- `resume/`: every version of your resume, named `resume_<yymmdd>.pdf` (and `.docx` if you edit in
  Word). Claude reads these but never edits them; resume feedback comes as suggestions.

`example/` and this README come from the template; don't edit them. Everything else here is yours.
